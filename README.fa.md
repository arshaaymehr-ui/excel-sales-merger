# ادغام خودکار گزارش فروش شعب

این اسکریپت فایل‌های اکسل فروش چند شعبه را می‌خواند، داده‌ها را تمیز می‌کند، ادغام می‌کند و یک گزارش اکسل آماده با شیت خلاصه می‌سازد.

## مشکلی که حل می‌کند

اگر هر ماه باید فایل‌های اکسل شعب مختلف را دستی کپی و ادغام کنید و جمع فروش را حساب کنید، این اسکریپت همه‌ی آن را در چند ثانیه انجام می‌دهد.

## امکانات

- ادغام همه‌ی فایل‌های اکسل یک پوشه
- پاکسازی خودکار: خانه‌های خالی، متن به‌جای عدد، ارقام فارسی، مقادیر منفی و ردیف‌های تکراری
- خلاصه فروش هر شعبه و هر محصول
- خروجی اکسل مرتب با سه شیت و جداکننده هزارگان

## نحوه اجرا

1. کتابخانه‌ها را نصب کنید: `pip install -r requirements.txt`
2. فایل‌های اکسل را در پوشه `data` بگذارید.
3. اجرا کنید: `python merge_sales_reports.py`
4. فایل `sales_report.xlsx` ساخته می‌شود.
